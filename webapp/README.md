# PRP AI Workforce Accelerator

A premium, interactive consulting pitch report built for PRP Services Private Limited.

## Tech Stack
- React 18
- TypeScript
- Vite
- Tailwind CSS v4
- Framer Motion
- Lucide React
- React Router DOM

## Development
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Structure
- `/src/components`: UI components
- `/src/data`: Structured content and data driving the application
- `/src/pages`: Main pages including the Executive Report PDF view
- `/src/index.css`: Tailwind configuration and global styles
